```javascript

  {
    id: 'dole-whip-mk',
    name: 'Dole Whip',
    park: 'Magic Kingdom',
    location: 'Aloha Isle - Adventureland',
    price: 5.99,
    category: 'snacks',
    imageUrl: '/images/dole-whip.jpg',
    xp: 10,
    isBossFood: false,
    isLegend: true,
    isHiddenGem: false,
    description: 'Iconic pineapple soft-serve, refreshing and dairy-free'
  },
  // ... rest of items
];
```

2. Create script `scripts/seedDatabase.js` to upload to Firestore

3. For images, either:
   - Use placeholder service: `https://placehold.co/400x300?text=[FoodName]`
   - Find/create actual food images and upload to Firebase Storage
   - Use AI image generation for consistent style
